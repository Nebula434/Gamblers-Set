# Installation

1. Download the latest release `.zip`.
2. Extract it into your Balatro Mods folder:

```text
AppData\Roaming\Balatro\Mods
```

After extracting, your directory should look like:

```text
AppData
└── Roaming
    └── Balatro
        └── Mods
            └── GamblersPlay
```

Launch Balatro and enjoy.
